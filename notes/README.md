# Notes

Unreviewed material. Kept because it is useful, filed here because it has not
been settled.

The difference from [`decisions/`](../decisions) is standing, and it matters
more than it looks. A document in `decisions/` records something that was
argued, measured, and agreed — usually over several attempts, often reversing an
earlier position. A document here was written once, by somebody or something
thinking out loud, and has not been reconciled against the rest of the project.

Both can be useful. Only one carries authority, and a directory name is the most
reliable way to say which — a status line at the top of a file is easy to skip,
and easier still for a model summarizing it.

## If you are adding something here

Say when it was written, what it had not read yet, and what it has not been
checked against. The value of an unreviewed document is entirely in knowing that
it is one.
