The Protocol

StreetMesh is an open source framework for spatially organizing the Web, built on open standards and existing protocols. This is its protocol: the rules that let people, machines, and places coexist on the Web with the fluidity and orientation we already have in the physical world.

Start hereStreetMesh on GitHub

What this is

A webpage is not only graphics on a screen — it can be a room you walk through. A dashboard is not only data — it can be a place you stand in. The guides below start from how the Web got here and work toward what it takes to build somewhere people can actually be.
